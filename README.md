# saucedemo
#Test Plan Document of SauceDemo 
Overview
This test plan describes how manual testing will be conducted for the Sauce Demo (Swag Labs) website.
Sauce Labs provides Sauce Demo as a practice e-commerce application for UI and automation testing. The application includes login functionality, product listing (inventory), cart management, and a checkout process.
The primary objective of this testing is to verify that all core functionalities of the website work correctly, reliably, and as expected under different conditions.
Manual testing will focus on:
Login functionality
Product listing and cart behavior
Checkout process
Logout functionality
UI and navigation validation
Testers will execute test cases step by step and compare actual results with expected results. Any identified defect will be documented with detailed information for analysis and resolution.
